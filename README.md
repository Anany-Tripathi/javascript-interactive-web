# BrightSpace — Interactive JavaScript Web Experience

A responsive frontend demonstration for a JavaScript internship task.

## Files
- `index.html` — semantic webpage structure
- `style.css` — visual design, responsive layouts, and dark-theme styles
- `script.js` — JavaScript event handling and DOM manipulation

## Interactive features
- Greeting form updates text without reloading the page.
- Theme switcher toggles light and dark themes.
- Details button expands and collapses extra content.
- Mobile navigation menu opens and closes.

## Responsive design
CSS media queries adapt the layout at tablet and mobile widths. The page uses a flexible grid, responsive typography, and a mobile navigation menu.

## How to test
Open `index.html` in a browser. Enter a name in the greeting form, switch the theme, expand the details, and narrow the browser window to test the mobile layout.

This is a sample learning project. Review it against the exact wireframe and instructions provided by your internship before submitting.
